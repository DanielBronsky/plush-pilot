# Plush Pilot

Браузерная аркада-стрелялка: плюшевый Бубуш на игрушечном самолётике против волн злых игрушек. TypeScript + PixiJS 8, графика рисуется кодом.

```
npm install
npm run dev      # http://localhost:5173 (?platform=local — имитация рекламы)
npm run check    # типы + линтер + тесты + сборка
```

- `DESIGN.md` — замысел игры.
- `NEXT_PROMPT.md` — промт для продолжения работы с ИИ-ассистентом.
- `src/config.ts` — все настраиваемые числа.
- `src/core/sim.ts` — симуляция боя (без графики, с тестами).
